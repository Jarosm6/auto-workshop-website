# Auto Workshop Website

A responsive website created for a local automotive workshop specializing in wheel alignment and suspension repairs.

The project was built as a real-world website for an existing business, with a focus on simple navigation, responsive design and easy access to the most important information for customers.

## Features

- Responsive layout for desktop, tablet and mobile devices
- Image slideshow
- Contact information displayed in modal windows
- Direct phone call button
- Google Maps navigation
- Embedded Google Maps location
- Google Reviews integration
- Links to the workshop's social media

## Technologies

- HTML5
- CSS3
- JavaScript

## Purpose

This project was created for a real local automotive workshop.  
It is also included in my portfolio as an example of designing and developing a responsive business website from scratch.
